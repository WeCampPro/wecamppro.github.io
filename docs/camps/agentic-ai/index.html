تصمیم سریع

این کمپ برای چه تغییری طراحی شده؟

هوش مصنوعی دیگر فقط یک دستیار پاسخ‌گو نیست. در این کمپ با نسل جدید سیستم‌های عامل‌محور کار می‌کنید؛ سیستم‌هایی که می‌توانند برنامه‌ریزی کنند، ابزار به‌کار بگیرند و بخشی از اجرای کار را مستقل پیش ببرند.

مسیر یادگیری از مبانی LLM و مهندسی پرامپت شروع می‌شود و به طراحی عامل‌ها، پیاده‌سازی ابزار، CrewAI، LangGraph، Arshai، همکاری چندعامل و استقرار می‌رسد.

در پایان کمپ فقط با مفهوم Agent آشنا نیستید؛ می‌توانید یک سیستم عامل‌محور را طراحی، پیاده‌سازی، ارزیابی و برای ارائه آماده کنید.

مناسب برای

  • توسعه‌دهندگانی که با Python کار کرده‌اند و می‌خواهند وارد ساخت محصول‌های AI شوند.
  • افرادی که می‌خواهند فراتر از استفاده از چت‌بات‌ها، معماری سیستم‌های عامل‌محور را بفهمند.
  • تیم‌هایی که به نمونه عملی و قابل توسعه برای اتوماسیون هوشمند نیاز دارند.

پیش‌نیاز

  • تجربه پایه در Python
  • شناخت مفاهیم Object Oriented
  • آشنایی مقدماتی با API

جزئیات سرفصل‌ها

ماژول ۱: مبانی AI و LLM

با اصول پایه هوش مصنوعی و مدل‌های زبانی بزرگ آشنا می‌شوید. کار با APIها و چارچوب‌های Agentic AI را تجربه کرده، با CrewAI، LangGraph و Pydantic AI آشنا می‌شوید و برای ساخت عامل‌های هوشمند آماده می‌شوید.

ماژول ۲: اصول مهندسی پرامپت

یاد می‌گیرید چگونه پرامپت‌های مؤثر بسازید و آن‌ها را بهینه کنید. تمرین عملی این بخش ایجاد یک کتابخانه پرامپت مستندسازی‌شده است.

ماژول ۳: اصول سیستم‌های عامل‌محور

مفاهیم Agency، Autonomy و معماری‌های مختلف عامل‌ها بررسی می‌شود و تفاوت Workflow و Agent برای کاربردهای واقعی روشن می‌شود.

ماژول ۴: ذهن عامل‌ها

ساختارهای دانش، مکانیزم‌های استدلال، تصمیم‌گیری و برنامه‌ریزی در عامل‌های هوشمند معرفی می‌شوند.

ماژول ۵: توسعه عملی عامل‌ها

ابزارهای سفارشی برای عامل‌ها تعریف و پیاده‌سازی می‌شوند و چارچوب‌های CrewAI و LangGraph در عمل به کار گرفته می‌شوند.

ماژول ۶: همکاری چندعامل

سیستم‌های چندعامل با نقش‌های مشخص طراحی و اجرا می‌شوند؛ از جریان کار تا مدیریت ارتباط و هماهنگی اطلاعات.

ماژول ۷: قابلیت‌های پیشرفته

خودبازبینی، اصلاح خطا، معماری حافظه و طراحی سیستم‌های پیچیده آموزش داده می‌شود.

ماژول ۸: تولید و استقرار

چالش‌های تولید و استقرار عامل‌ها، نظارت، امنیت، نگه‌داری و اجرای پروژه‌های پایدار پوشش داده می‌شود.

رزومه و مصاحبه

یاد می‌گیرید چطور پروژه را روایت کنید، پورتفولیوی شخصی بسازید و برای مصاحبه‌های شغلی آماده شوید.
